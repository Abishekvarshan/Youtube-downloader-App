STREAMLINE FOR WINDOWS — v2.0.0

INSTALL
1. Extract this ZIP to a folder where your Windows account can create files, such as Documents\Streamline.
2. Keep the assets folder beside Streamline.exe.
3. Run Streamline.exe. No Python installation is required. Microsoft Edge WebView2 Runtime is required; install the Evergreen Runtime from https://developer.microsoft.com/microsoft-edge/webview2/ if prompted.

Streamline stores its app settings, queue, and downloads in a data folder beside the executable. Keep the app in a writable folder.

Only download videos you own or are permitted to save. Follow YouTube's terms and applicable copyright law.
