STREAMLINE FOR WINDOWS

INSTALL
1. Extract this ZIP to a folder where your Windows account can create files, such as Documents\Streamline.
2. Open the extracted folder and run Streamline.exe.
3. If Windows says WebView2 is missing, install the Microsoft Edge WebView2 Evergreen Runtime from:
   https://developer.microsoft.com/microsoft-edge/webview2/

Keep the assets folder beside Streamline.exe. Streamline saves its app data and downloads in a data folder beside the executable.

Only download videos you own or are permitted to save. Follow YouTube's terms and applicable copyright law.
