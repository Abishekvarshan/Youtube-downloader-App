Your videos,

Streamline is a simple desktop app for saving and organizing videos you have permission to download.

↓ Download for Windows ZIP package · Windows 10/11 · No Python setup
01

Download

Save the ZIP package to your computer.

02

Unzip

Extract it to a folder you can write to, such as Documents.

03

Open Streamline

Run Streamline.exe. Your downloads and app data stay in that folder.

First-time setup

Streamline needs the Microsoft Edge WebView2 Runtime. Most Windows PCs already have it. If the app asks for it, download the Evergreen Runtime from Microsoft.

Only download videos that you own or are authorized to save. Follow YouTube’s terms and applicable copyright law. Streamline is an independent app and is not affiliated with YouTube.
